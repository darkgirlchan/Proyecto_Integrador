# Proyecto_Integrador

## Objetivo

El objetivo de este aplicativo es la publicidad para tener nuevos estudiantes y administracion de las notas y asistencias de los estudiantes de la Institucion Educativa el último día 

## Funcionalidad

este aplicativo es una simulación de como seria la interfaz grafica para usuarios sin sesión como usuarios con sesión sin uso de autentificacion o backend activo actualmente por ello cuenta con lo siguiente

### Contenido

#### **Pagina de inicio (index.html):** 
esta es la pagina principal y de inicio la cual contendra informacion como lo es: 
- Barra de navegación: logo y acceso al login.
- Contenido promocional.
- Sección “Conócenos”.
- Sección de instalaciones y servicios.
- Sección de matrícula o inscripción.
- Footer con información.

#### **Pagina de inicio (login.html):**
esta es la pagina donde se simulara el inicio de sesion de los usuarios para que puedan ingresar al apartado interno de administracion de notas de los estudiantes contendra informacion como lo es:
- Formulario de inicio de sesión.
- Campo de correo electrónico.
- Campo de contraseña.
- Botón de inicio de sesión.
- Botón de inicio de sesión con microsoft.
- Botón para volver al inicio

#### **Pagina de administracion (admin.html):**
esta es la pagina que aparece una vez se realice el login donde los usarios podran ver todo lo relacionado a sus notas  y asistencia,  contendra informacion como lo es:
- Barra lateral de navegación (Sidebar).
- Un resumen general
- Gestión de notas.
- Gestión de asistencias.
- Informacion del Estudiante.
